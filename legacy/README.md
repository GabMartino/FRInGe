# Legacy visualization prototype

This directory preserves the earlier high-instrumentation trajectory notebook
and helper implementation for historical reference. It is not imported by the
paper benchmark suite and was moved here specifically to avoid confusing it
with the canonical implementation under `methods/FisherRaoIG/`.

The notebook records the pre-reorganization import layout and is not guaranteed
to execute without adaptation. Use the root quick start and `methods/` code for
current experiments.
